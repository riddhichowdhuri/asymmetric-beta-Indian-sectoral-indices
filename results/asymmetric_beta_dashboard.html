Model Specification
ARIMAX Asymmetric Beta Framework
rsector,t = α + β⁺·D⁺t + β⁻·D⁻t + ARMA(p,q) errors
where: D⁺t = max(rmkt,t, 0) — positive market return (Up regime)
D⁻t = min(rmkt,t, 0) — negative market return (Down regime)
Best (p,q) selected by AIC grid search over p,q ∈ {0,1,2,3}
H₀: β⁺ = β⁻ tested via Wald test (χ² with 1 df)
The ARMA component absorbs serial autocorrelation in sector returns, yielding more efficient estimates of β⁺ and β⁻ than plain OLS. Splitting the market return into D⁺/D⁻ regressors within a single model allows joint estimation with full covariance structure — critical for the Wald test.

Diagnostic Legend
ADF Test
H₀: Series has a unit root (non-stationary).
Reject at p<0.05 → series is stationary → valid for ARIMAX.
KPSS Test
H₀: Series is stationary.
Fail to reject at p>0.05 confirms stationarity (complements ADF).
Ljung-Box(10)
H₀: No serial autocorrelation in residuals (up to lag 10).
p>0.05 on ARIMAX residuals → model captured all AR/MA structure.
ARCH-LM(5)
H₀: No ARCH effects (no volatility clustering).
p<0.05 → GARCH extension recommended for better variance modelling.
Jarque-Bera
H₀: Residuals are normally distributed.
Fat tails are common in financial returns — non-normality expected.

Methodology Summary
Data
Source: Yahoo Finance via yfinance
Frequency: Weekly (1wk)
Period: Jan 2018 – Dec 2025
Returns: Log returns rt = ln(Pt/Pt−1)
Benchmark: Nifty 50 (^NSEI)
Model
ARIMAX(p,0,q) via statsmodels.ARIMA
Exogenous: D⁺ and D⁻ market splits
Order: AIC grid search (p,q ∈ 0–3)
Baseline: ARIMAX(0,0,0) for AIC gain
CIs: 95% from model.conf_int()
Tests
Stationarity: ADF + KPSS
Serial corr: Ljung-Box (lag=10)
Heteroscedasticity: ARCH-LM (lag=5)
Normality: Jarque-Bera
Asymmetry: Wald test (χ², df=1)
