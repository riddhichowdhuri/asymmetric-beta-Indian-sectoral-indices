# Data

The original workbook contains the weekly adjusted closing prices and log returns used in the supplied analysis.

The repository intentionally does not create a second copy of the raw market-data table here.

See:

- `../results/Asymmetric_Beta_Analysis_OLS.xlsx`
- `../notebooks/asymmetric_beta_analysis.ipynb`

The notebook specifies Yahoo Finance via `yfinance` as the data source and uses weekly data from January 2018 through December 2025.
